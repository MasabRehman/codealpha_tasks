info UNDERSTANDING MODEL LIMITATIONS

1. Why it's not perfect (The Domain Gap): This model was trained on the IAM Dataset (connected, lowercase cursive written with a pen). If you draw giant, disconnected, ALL-CAPS block letters with a thick mouse marker, the neural network gets confused because it has never seen that style before! It will try to mathematically map your block letters to the closest cursive shapes it knows.

2. Why 100% accuracy is impossible at this scale: Commercial OCR (like Google Lens) trains on millions of images using massive Transformer models and multi-gigabyte Language Models to auto-correct typos. This is a lightweight CRNN trained on a tiny dataset for a few epochs on a single GPU. Without a Language Model, it relies purely on visual shapes.

3. How to get the best results:
• Drawing: Write a fully connected, lowercase cursive word horizontally with a thin stroke size.
• Photos: Ensure the paper has no shadows, no blue notebook lines, and the word is completely horizontal. Crop the photo tightly around a single word before uploading!
